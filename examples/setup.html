让 Edge 和本地服务配对

1. 加载插件

在 Edge 地址栏输入 edge://extensions，开启“开发人员模式”，点击“加载解压缩的扩展”，选择工具文件夹中的 extension 文件夹。

2. 填写配对码

点击插件的“配对设置”，复制下面的配对码，粘贴后点击“保存并检查连接”。

PAIRING_TOKEN

这是本机服务生成的配对码，不是云端 API 密钥。不要把它发给其他人。

3. 回到网页翻译图片

点击插件的“翻译当前页”。图片中的英文会逐张翻译，右下角可切换原图或停止。若图片来自其他域名，勾选插件面板中的“允许读取跨域图片”。
