# 图片汉化 · Edge 本地版

适用于这台 Apple Silicon Mac 上的 Microsoft Edge。0.2.0 版支持 **英文、韩文图片 → 简体中文**，在原图的文字位置覆盖白底中文框。模型已下载、运行环境已准备，不需要云端 API 密钥。

## 开始使用

1. 双击本文件同目录的 `启动.command`，保留启动窗口。若 macOS 提示需要权限，只对本工具授权即可。关闭窗口或按 Control+C 停止服务。
2. 在 Edge 地址栏输入 `edge://extensions`。开启“开发人员模式”，点击“加载解压缩的扩展”，选择同目录的 **extension 文件夹**。
3. 打开 `http://127.0.0.1:17863/setup`，复制本地配对码。点击插件的“配对设置”，粘贴后点击“保存并检查连接”。
4. 回到要阅读的普通网页，点击插件的“翻译当前页”。网页右下角会显示进度、原图切换、失败重试和停止按钮。

普通网站的图片经常来自 CDN。如果出现跨域图片读取失败，请在插件面板勾选“允许读取跨域图片”，再次点击翻译，并在 Edge 的权限提示中允许。也可以随时在“配对设置”撤回此权限。

当前任务运行期间本地服务已启动，可先打开 `http://127.0.0.1:17863/demo` 体验。若重启电脑或服务退出，再双击 `启动.command`。

## 已实现

- macOS Vision 本地文字识别；英中、韩英离线模型翻译；不调用外部翻译 API。
- 点击开始后自动处理当前页的普通 `<img>` 图片，优先处理靠近当前视口的图片。
- 支持 `srcset` 当前来源、滚动后加载、动态插入和图片来源变更。
- 根据图片位置、比例及 `object-fit` 更新文字框；不改原图片文件，不阻挡原有图片链接。
- 显示原图 / 中文、停止并移除、失败提示和重试；同图内存缓存。
- 跳过很小的图标和无可识别英韩文字的图片。超过 12 MB 或 2400 万像素会提示缩小后重试。

## 现有限制

- 支持英文和韩文。韩语先翻译成英语再译成中文，可能损失语义；日文等其他语言尚未支持。
- CSS 背景图、canvas、视频、PDF 阅读器、跨域 iframe 和 Shadow DOM 内的图片暂不扫描。
- 旋转、倾斜、复杂透视、特殊裁切、页面元素遮挡以及复杂 `object-position` 情况，可能无法准确覆盖。检测到直接旋转/倾斜的图片会跳过。
- 文字识别会有误差。艺术字体、手写、小字、复杂漫画气泡和低对比度图片尚未实测；不能保证所有英文都被识别。
- 白底中文框不会修复原图背景。特别狭窄的文字区域可能需要缩小字号；可切回原图对照。
- 登录保护、防盗链的跨域图片可能读不到；下载原图时不发送网站登录凭据。
- 自动处理只在点击开始后的当前页面生效。刷新网页、切换到新的页面后需要重新点击开始。
- 停止会移除覆盖并停止后续读取；本地服务已接收的那一张图片可能仍会完成处理。

## 本地数据与权限

- 服务只监听 `127.0.0.1:17863`。图片在本机识别、翻译；插件仍需从原网站读取图片，不会将图片发送给第三方翻译服务。
- 模型首次下载需要网络；正常识别、翻译不需要网络。网页本身是否可离线打开取决于原网站。
- 图片识别时在本工具的 `runtime` 下创建临时图片，识别结束自动删除。
- 图片摘要、原文、译文和任务状态只保存在进程内存。缓存上限 64 张；服务退出清除。配对码保存在本工具及插件的本地配置中，不使用浏览器同步。
- 插件默认权限：点击后操作当前页面、本地配置、本地服务连接。跨域图片权限是可选项，需由用户主动开启。
- 未添加开机启动项，未修改系统 Python，未提交、推送或发布插件。

## 重新安装 / 移动工具

当前文件夹可以直接使用。若移动文件夹导致 Python 环境失效，可保留 `models`、`extension`、`service`、`examples` 及命令文件，在新的位置重新创建本工具的运行环境。`安装.command` 需要 uv、Python 3.12 和 Xcode Command Line Tools，只会安装到本工具目录；首次安装下载依赖和约 67.4 MiB 的英中模型和约 113 MiB 的韩英模型。

## AI 上下文翻译（0.3.0）

打开 http://127.0.0.1:17863/ai-settings，填写完整接口地址（以 `/chat/completions` 结尾）、模型名、密钥，保存后在插件面板选择“AI 上下文”。原有“本地快速”继续离线运行。更新后需在 Edge 的扩展页点击“重新加载”，并刷新要翻译的网页。如果原先加载了单独解压的副本，请先用新版 extension 文件夹替换。

支持 OpenAI 兼容的 Chat Completions 接口，原生 Anthropic / Gemini 等不同协议不可直接填写。远程地址要求 HTTPS，本机服务允许 HTTP。默认不发送 response_format 参数；服务商支持 JSON 输出模式时可勾选。密钥留空会保留原值；勾选清除可删除。密钥文件 runtime/ai-config.json 权限为 600，未加密，不加入插件包。

识别仍由 macOS Vision 本地运行，不向 API 上传原图。每轮先识别当前已加载的普通图片，结合标题、可读取的网页正文、图片原文及已有译文，分批翻成简体中文；英文和韩文都可用。每批 12 框，每轮最多 1000 框，单图最多 160 框。上下文超过设置上限会截取并显示提示。动态新图片会继续处理，并携带已有文字和译文；没有自动抓取尚未加载的整本漫画或其他页面。

配置保存不调用 API。开始 AI 翻译、重试或重新开启会产生请求；费用取决于服务商。停止会移除覆盖并停止继续扫描，已经交给本地服务的任务可能仍完成，不能保证撤销在途 API 费用。接口报错或返回遗漏、重复编号的译文会显示失败，不自动改为本地译文。

风格可填写，例如：自然的简体中文；漫画对白口语化，保留人物性格；不要逐字硬译；人名和术语统一；保留原文信息，不补写剧情。真实效果取决于模型、上下文和 OCR 准确度。


## 0.3.1：长任务连接修复

后台现在只提交任务和查询任务状态，不再通过一次消息等待整页翻译。网页每次携带任务编号查询，因此后台休眠再唤醒时不需要重新提交。状态查询连接异常最多重试两次；提交任务不会自动重试，避免在回复丢失时重复调用付费接口。最大等待时间调整为 75 分钟。

安装更新后必须在 Edge 扩展页重新加载插件，再刷新正在翻译的网页；旧网页已注入的脚本不能仅靠“重试失败图片”更新。配置和密钥不需要重填。


## 0.3.2：韩中直译与 AI 格式约束

离线韩语已更换为 M2M100 418M 的 CTranslate2 INT8 模型，设置源语言 __ko__ 与目标语言 __zh__，直接输出中文；不再调用韩英模型。原有韩英文件保留，但不再被加载。模型约 473 MiB，下载于 gn64/M2M100_418M_CTranslate2 的固定版本 18e406c615ef2991fa74d53734bf66b0a6b10cb4；这是社区转换版本，原始模型为 Meta 的 facebook/m2m100_418M。文件清单和校验值见 service/direct-model-manifest.json。安装脚本只在文件缺失或校验失败时下载。

DeepSeek 官方域名自动发送 JSON 输出参数，并提供有效 JSON 示例；当前 deepseek-flash / deepseek-v4-pro / deepseek-v4-flash 关闭思考模式以专注翻译。每批最多 12 框，每批仍携带相同的网页和整页图片上下文；减少单批框数会增加 API 请求数量。返回空内容、非 JSON、编号遗漏/重复、目标外编号、回复截断会分别说明批次和原因；不会自动重交付费翻译请求。直接翻译减少了中转步骤，不代表离线译文一定自然或准确。


## 0.3.3：局部保留译文与补译

AI 每个请求仅使用局部编号 1–12；网页图片编号在本机映射，上下文与历史译文不再携带可混淆的框编号。完全相同的重复编号与译文合并；同一编号的译文冲突、遗漏或无效时，该框继续显示原文，其余校验有效的框显示中文。无法安全解析或出现目标外编号时，仅该批保持原文；网络/鉴权失败会停止后续请求并保留此前有效译文。

面板区分完成、部分完成、失败。“重试未完成部分”仅提交没有译文的文字框，保留已有译文；该操作仍可能产生 API 费用。没有新增自动翻译重试请求。


## 0.3.4：进度监控与检查

网页右下角面板自动显示整体处理百分比、当前阶段、已识别图片数、已显示中文框数、AI 当前批次/总批次、本轮成功与异常框数、用时、任务编号和最近连接时间。AI 整体处理百分比将识别与翻译两个阶段各计一半，包含已处理但失败的部分；100% 表示本轮处理结束，不保证全部翻译成功，请同时查看部分完成和失败数。当前已加载图片数量变化时，进度分母随之更新。

“检查当前进度”仅查询当前在途任务状态，不创建翻译请求，不调用远程 AI。无在途任务时会显示当前没有在途任务。任务阶段超过 100 秒未变化时提示检查连接，这不直接判定任务失败；HTTP 查询正常和 AI 进度正常是不同的信息。当前状态自动刷新，最近错误保留在面板中。

本轮按用户要求不做测试，实际页面由用户验收。更新后重新加载插件，并刷新已有网页。API 配置保留。


## 0.3.5：隐藏翻译面板

点击右下角“隐藏面板”，面板收起为小“译”按钮；点击“译”重新展开。隐藏只影响面板，图片中文覆盖、翻译任务和进度查询继续运行。重新开启一轮翻译时默认展开面板；“停止并移除”会移除面板和小按钮。更新后重新加载插件并刷新已有网页。
