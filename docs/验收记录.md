## 已验证的实际流程

在 Edge 打开 `http://127.0.0.1:17863/demo`，通过页面按钮操作真实本地 OCR、离线模型和与插件共用的覆盖程序；没有用预写中文或模拟翻译响应。

| 流程 | 实际结果 |
|---|---|
| 开始翻译两张英文图片 | 状态显示 **已处理 2 张 / 待处理 0 张 / 失败 0 张**，可见真实中文译文 |
| 原图与中文切换 | 中文框隐藏后恢复英文原图，再切换显示中文 |
| 中文状态下点击原图片链接 | 仍进入 `#more`，页面滚动后文字框跟随图片 |
| 图片缩小、带留白的 object-fit: contain | 实际截图中中文框与缩小后的文字位置对齐 |
| 替换为无文字图片 | 旧中文字框被移除，无文字图片不添加中文字框 |
| 动态插入新图片 | 自动扫描和处理，状态变为 **已处理 3 张**，新图片显示中文 |
